    What this is not

    

      Not a password manager. It remembers nothing, on purpose: no history, no
      favourites, no settings, nothing in localStorage, no cookies, no service
      worker. Close the tab and the password is gone. Write it down, or put it
      in a manager you trust.
    

    

      What it cannot stop: a browser extension with page access, a compromised
      OS, a keylogger, a shoulder-surfer, a screen recording, or a clipboard
      manager that keeps what you copy. Nothing rendered on a screen is private
      from the machine that renders it.
    

    

      How to check us: open the network tab and reload: zero requests. Open the
      application tab: empty. Read the file — it is the program and its own
      source. Or run npm run verify in a clone.
    


    

      Passphrase mode uses the EFF Long Wordlist.
      Character sets are ASCII only. No analytics, no cookies, no fonts, no CDN, no
      dependencies, no build step required to run this page.
